# 虚构试用需求

做一个面向英语用户的 Printer App 低保真原型，范围为 Home 和 Connect Printer。
Home 有产品标题、未连接提示、Connect Printer 按钮、Photos 与 Documents 打印入口。
Connect Printer 有返回入口、设备说明、一台名为 Office Printer 的虚构设备、Connect 按钮。
UI 英文，右侧中文说明，采用编号。先连接再选择内容，Home 仍然是一个完整主页。
默认只画静态页面，点击结果在说明里写清楚。没有真实扫描或打印能力；不加订阅、广告、登录。
生成 HTML 和说明后，写入自己的空白测试 RP，再试一次原位修改。
