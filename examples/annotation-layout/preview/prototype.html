S01 · 页面说明
1、Home 展示当前已导入的文件；本画板中的文件名为示例数据。 2、进入时有文件展示 S01；没有文件展示 S02。二者属于同一个 Home 页面。
S01 · ① 文件及导入操作
1、点击文件进入该文件详情；详情页不在本次绘制范围。 2、点击 Import 打开文件选择器。成功导入后刷新当前列表；取消选择不改变已有文件。 3、导入失败时保留已有列表，提示无法导入，可再次点击 Import 重新选择。
S02 · 页面说明
1、没有任何已导入文件时，展示 No files yet 和 Import。 2、此状态不是权限被拒绝、加载中或筛选无结果，不添加这些未经要求的画板。
S02 · ② Import 操作
1、点击 Import 打开文件选择器，成功导入后切换为 S01。 2、取消选择或导入失败，保留空状态；失败时提示无法导入，允许重新选择。
美术交付说明
1、同一 Home 的 2 个状态稿复用页面框架，无独立插画资源。蓝色编号是评审标注，不属于 App UI。 2、本示例不接入真实数据，不制作点击交互。
