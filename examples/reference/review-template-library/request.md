# 通用 RP 评审模板库

用户要求读取此前提供的全部 RP，提炼统一规范；所有后续模板按这种“左侧页面效果、右侧中文需求说明”的方式生成，并通过原生桥接放入 Axure。

本示例只承载通用信息结构和排版，不继承任何原产品的功能、文案、价格、广告、权限、健康阈值或内部链接。模板包括：需求概览、单页面、多状态、流程、局部迭代/Bugfix、共享规则与表格。

视觉骨架与业务说明目录必须分开：页面框、框外标题、蓝色编号和右侧说明可以复用；说明标题先从当前页面的用户任务、业务对象、操作、状态、数据影响和边界生成。“页面说明/页面进入/交互说明/异常处理”只按需出现，任何单一示例产品都不得成为默认章节和状态机。
