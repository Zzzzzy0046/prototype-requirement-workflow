# Reference Selection

这是通用评审模板的脱敏教学案例，不是一个真实产品项目。它用六个独立演示页展示不同交付形态，因此每页分别选择主模式；不能把六个模式合并成一款产品的页面树。

| 演示页 | 主模式 | 辅助参考 | 借用范围 |
| --- | --- | --- | --- |
| 需求概览 | 无产品页面模式 | `house-review` | 项目范围和页面目录的评审表达 |
| 单页面 | Home / 主任务入口 | 无 | 单画板与业务模块说明 |
| 同页多状态 | Home / 主任务入口 | 状态表达 | S 状态画板和蓝色需求模块编号分离 |
| 流程 | Global flow | 无 | 顺序、条件和回退的静态表达 |
| 局部迭代/Bugfix | Iteration / Bugfix | Detail / Result | 旧→新、影响范围、沿用和回归点 |
| 共享规则与表格 | Global flow / Cross-page rule | Ads / Push / Shared policy table | 一个规则源、多页引用和行列语义 |

统一借用：页面框、框外标题、蓝色编号、紧邻右侧说明、独立可编辑控件。

统一禁止继承：示例产品名称、UI 文案、价格、权益、广告、权限、成功判定、数据规则、版本号和页面数量。真实任务必须重新生成 `reference-selection.md`，只选择一个主模式，必要时最多两个辅模式。
