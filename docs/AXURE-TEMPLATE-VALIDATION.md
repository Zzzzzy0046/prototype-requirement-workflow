## 统一表达规则

- 页面或状态效果位于左侧，中文需求说明位于右侧。
- 移动端主画板默认 360px 宽；同一功能的多个状态在同一个 Axure 页面并排表达。
- 页面标题、状态标题、编号标记、说明标题和说明正文使用统一层级。
- 页面说明、交互说明、页面状态、异常与边界、局部变更和共享规则根据需求类型选择，不机械堆叠全部章节。
- 美术交付说明只在确有图片、图标或动效资源需求时出现，并与 App UI 分离。
- 默认使用可编辑基础控件；不自动生成复杂动态面板或交互。
