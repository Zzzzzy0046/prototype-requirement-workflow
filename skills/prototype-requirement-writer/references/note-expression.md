# 说明块与表格表达

用户指定的原稿优先；以下是可选表达，不要求每页都出现。

| kind | 用途 | 编译效果 |
| --- | --- | --- |
| module / 未填 | 单模块说明 | 原有标题和正文，旧 key 与输出不变 |
| shared-rule | 多图/多页共同条件与例外 | 带灰框的独立说明块，正文保留适用页面 |
| change | 旧→新、影响和沿用 | 带蓝框的改动块；用文字写明差异，不只靠颜色 |
| art | 美术表达、资源复用/新增 | 红色标题、正常正文，放在 App 画框外 |

notes 仍用 key/title/lines/x/y/width。共享说明不一定配一个手机屏，局部改动不重绘无关页面；来源明确且当前通道可用时保留既有页面效果。不能称基础控件重建为原库复用。

对同步方向、通知计划、配置等重复字段，可在 note 上增加：

```json
{"key":"sync","kind":"shared-rule","title":"跨页同步规则","lines":["1、仅以下范围共享。"],"width":640,"table":{"columns":["来源","目标","规则"],"rows":[["Home","History","任务失败后显示重试入口"],["History","Home","重试成功后刷新状态"]]}}
```

table.columns 为表头，rows 每行单元格数一致；正文可为空但 lines/table 至少有一项。单元格保持换行与行列关系；不把有方向的同步简写成“全局同步”。条件/例外过长时分组或增宽，不靠极小字体。

HTML 和 Axure 使用同一编译结果：表格由可编辑矩形边框和文本控件重建，不是 Axure 原生 Table；不支持单元格合并、富文本混排或自动恢复原稿表格。Markdown 也输出真实表格，转义竖线和 HTML 文本。

kind 为 shared-rule/change 时增加 `note-<key>-box`。表格控件 key 含行列索引；已写入后改变类型、删正文/删行列可能触发底层“不支持移除”的保护。保留既有结构、原位改值最稳定；需要结构删减时先明确迁移方案，不删除映射或生成新 key 绕过。换角色可能影响旧控件层级，须原生渲染检查，不能假定框永远在旧控件下方。

程序检查说明块彼此重叠，但不能替代画面与说明交叉遮挡、真实字体换行及原稿一致性的目视核对。原稿含图片表格时先实际读内容，不仅提取图片标题。
