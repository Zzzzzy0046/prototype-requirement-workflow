# 安卓历史评审格式

仅用于已有 `android-review` 项目继续修改。新项目统一使用 house-review，当前字体与说明列参数相同，但名称不再把跨产品评审格式绑定到 Android。其他平台或用户指定模板优先，不必为了选择模板打断用户。

## 来源与边界

几何与字体来自已解析的需求常用库“安卓”模板记录：画框 360×640；画板标题 Arial 13.5pt 加粗；说明标题 Arial 10.5pt 加粗、正文 Arial 9pt、#333333；说明宽 322px。相对位置：画框右侧 45px 是编号起点，编号到说明文本起点 38px；示例两组画板起点相差 810px。这里只分发抽象参数，不分发私人原稿、库文件或控件 ID。

frame 白底、#797979 直角描边及蓝色编号 #3758CC 沿用先前基础控件重建约定。26px 外圈、22px 内圆取自模板几何。红色 #D9001B 美术标题属于之前演示的标注选择，不是原库统一颜色，只有当前项目确有美术交付需要才采用；不得默认写“需要美术出图 * 1”。

原始富文本行距、内边距、Layer 分组与样式继承没有无损导入。当前 profile 提供近似布局高度估算，必须检查长中文和长英文的实际渲染，不声称像素级复刻或原生组件复用。

## 应用

scene 顶层设置 `"noteProfile":"android-review"`，编译器使用上述说明字体和 322px 默认列宽，而不是旧固定 14/11pt。notes 的 x/y/width 仍可覆盖布局位置，keys 不变。默认 profile 不改变旧场景的样式与坐标。

Agent 按已读取模板创建 frame、review-title、number-marker 普通控件；不是编译器自动往所有页面塞手机框。建议使用完整示例 examples/clarification-home/，不要套用其中的业务内容。

若用户要求另一份模板，先提取其参数；如当前 profile 无法表达，明确说明并在项目内制定可验证适配，不暗改 android-review 的通用定义。原文太长时扩大说明区或按语义拆组，不能为了符合示例坐标缩字号或截断。
